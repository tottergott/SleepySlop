# SleepySlop

Монорепозиторий для совместных проектов. Каждый проект лежит в своей папке со своим README и окружением.

| Папка | Что это |
|---|---|
| [`voice_cloning/`](voice_cloning/) | Voice Arena: бенчмарк русских TTS с игровыми голосами (GLaDOS, Уитли, Кейв Джонсон, Пудж, Witch Doctor, Артас) — F5-TTS vs Silero→RVC vs Native/DSP |

## Правила

- Новый проект — новая папка в корне (`snake_case`), внутри свой `README.md` и `requirements.txt`.
- Секреты только в `.env` внутри проекта (в git не попадают). Веса моделей, датасеты и аудио не коммитим — их скачивают скрипты проекта.
- Работаем через ветки и pull request в `main`.
